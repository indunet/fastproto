2:Ta2c,<h2>Dynamic Offset with offsetRef</h2>
<h3>Overview</h3>
<p>Some formats store an absolute position in a header and place the actual data later in the file. Use <code>offsetRef</code> to point a field’s <code>offset()</code> to a previously decoded numeric field in the same class. The source field name must be prefixed with <code>$</code>.</p>
<h3>Rules</h3>
<ul>
<li>The referenced field must appear earlier in the class and be decoded before the target.</li>
<li>The referenced field must be a numeric type.</li>
<li>Works for most data type annotations that expose <code>offset()</code> (booleans use <code>byteOffset/bitOffset</code>, not supported).</li>
<li>If both <code>offset</code> and <code>offsetRef</code> are provided, <code>offsetRef</code> takes precedence (dynamic offset overrides static).</li>
<li>Validation: At least one of <code>offset</code> or <code>offsetRef</code> must be specified; otherwise resolving fails.</li>
</ul>
