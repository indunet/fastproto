<h3>Codecs</h3>
<ul>
<li>Serializer: <code>FastProtoSerializer</code> encodes objects to <code>byte[]</code>.</li>
<li>Deserializer: <code>FastProtoDeserializer</code> decodes <code>byte[]</code> to objects.</li>
<li>Serde: <code>FastProtoSerde</code> for Kafka Streams or unified configs.</li>
</ul>
<p>FastProto only handles the in-frame schema. Kafka provides message framing per record.</p>

<h3>Notes</h3>
<ul>
<li>Deserialization requires <code>fastproto.value.type</code>; otherwise, an exception is thrown.</li>
<li>Your POJO must be annotated with FastProto mapping annotations.</li>
<li>Coordinate schema layout between producers and consumers when evolving messages.</li>
</ul>
