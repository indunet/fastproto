1c:T31b9,<h1>Using APIs without Annotations</h1>
<p>Operate on byte buffers directly when you cannot or do not want to decorate classes with annotations.</p>
<h2>Overview</h2>
<p>FastProto offers two complementary ways to work without annotations:</p>
<ul>
<li>Chain APIs: fluent builders for decode/encode with field names for later mapping</li>
<li>Utility methods: static helpers to read/write primitive values</li>
</ul>
<h2>When to Use</h2>
<ul>
<li>Data objects come from third‑party libraries and cannot be modified</li>
<li>You need a quick script/tool to inspect or craft binary frames</li>
<li>Prototyping before locking a schema</li>
</ul>
<h2>Quick Steps</h2>
<ol>
<li>Decide buffer length and create/obtain the <code>byte[]</code></li>
<li>Use chain API or utilities to read/write values at specific offsets</li>
<li>If needed, map decoded values to a POJO by matching field names</li>
</ol>
<h2>Core Concepts</h2>
<ul>
<li>Addressing is 0‑based byte offsets; bit fields specify <code>byteOffset</code> + <code>bitOffset</code></li>
<li>Endianness: utilities accept <code>ByteOrder</code>; chain API variants have overloads too</li>
<li>Reverse addressing: use a fixed total length when writing near the tail</li>
</ul>

<h2>Best Practices &#x26; Troubleshooting</h2>

<li>Keep a single source of truth for constant offsets (centralize in one class)</li>
