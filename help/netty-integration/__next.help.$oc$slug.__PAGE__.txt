<h3>Codecs</h3>
<ul>
<li>Inbound: <code>FastProtoDecoder&#x3C;T></code> converts <code>ByteBuf</code> to a target object.</li>
<li>Outbound: <code>FastProtoEncoder</code> converts an object to <code>ByteBuf</code>.</li>
<li>Both can be annotated with <code>@Sharable</code> and reused across channels.</li>
</ul>
<p>Framing (fixed length, length-field, delimiter-based, etc.) should be handled by Netty.</p>

<h3>Multiple Types</h3>
<ul>
<li>Use a dedicated "type field" in the frame and route in an inbound handler.</li>
<li>Alternatively, bind a type per-channel and construct <code>FastProtoDecoder&#x3C;>(Type.class)</code> accordingly.</li>
</ul>
<h3>Zero-Copy (Optional)</h3>
<p>Current implementation copies <code>ByteBuf</code> to <code>byte[]</code>. A zero-copy path can be added later to read directly from <code>ByteBuf</code>.</p>
